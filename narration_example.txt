# Hinglish narration script for the Vimal Enterprises documentary.
#
# FORMAT
#   One cue per line, starting with the timestamp where it should begin:
#       00:05 यहाँ से शुरू होती है कहानी।
#   Optionally pin an explicit end to fit the cue into an exact slot:
#       00:18 --> 00:26 Kraft paper के विशाल reels यहाँ पहुँचते हैं।
#   Without an end time, a cue gets the room up to the next cue.
#   Lines starting with # are ignored. A line with no timestamp continues
#   the cue above it. Timestamps accept SS, MM:SS or HH:MM:SS. .srt works too.
#
# HINGLISH RULES (these matter — Sarvam degrades badly if you break them)
#   - Hindi words in Devanagari, NEVER romanised.
#       सही:  आपका order confirm हो गया है
#       गलत:  Aapka order confirm ho gaya hai
#   - English words stay in Latin script: machine, quality, plant, board.
#   - End a Hindi sentence with । and an English sentence with a full stop.
#   - Numbers over 4 digits need commas: 10,000 — otherwise they are read digit by digit.
