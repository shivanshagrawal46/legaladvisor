# VIMAL ENTERPRISES — Voice-over Script v2 (17 sections, 139 sec)
# Source: Vimal_Final_Voiceover_Script_v2.docx, "CLEAN SCRIPT" page.
#
# Two changes were needed to make this work well with Sarvam Bulbul v3:
#
# 1. Romanised Hindi converted to Devanagari. Sarvam's docs list romanised
#    Indic input as the single biggest cause of bad output. English industry
#    terms (carton, packaging, Corrugation, brand) stay in Latin script, which
#    is exactly how the model expects Hinglish.
#
# 2. The script's "…" pause notation is mostly rendered as commas. In Bulbul,
#    "…" means hesitation / trailing-off, and the docs warn that overusing it
#    sounds choppy. A comma is the correct mark for the short natural pause
#    this script intends. A few genuine trailing-off moments keep their "…".
#
# Section 1 starts at 0:01, per the direction note that the first second is
# music-only over black.
